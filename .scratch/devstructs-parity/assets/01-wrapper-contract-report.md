## 5. Byte-parity contract — details beyond AGENT-FIXUP.md

1. **Body framing**: stdout starts with `class` (or `//` comment) and **ends with `}\n\n\n`** — final brace + exactly two blank lines.
2. **Tabs everywhere**; no space-indented lines in any output.
3. **Class block layout**: ctors, one blank line, fields joined by `\n`, `}`. Empty class: two blank lines after last ctor.
4. **Blank-line separators between top-level blocks**: class→class = 2; containing class→first wrapper = **1**; wrapper→wrapper = 2; last wrapper→next class = **1**.
5. **Comments**: `# text` → `\t// text` at field position, or `// text` at column 0 above a class header. Bare `#` → `// ` (trailing space). Comments with no following directive are **dropped**. Blank xtoml lines never emit blank lines. `#Buffer: ...` commented-out directives are plain comments, kept in field-stream position.
6. **Buffer getters are deferred**: fields + Inline emit in source order; all buffer `get_X()` accessors emit at the **end of the class body**; wrapper classes emit immediately after the containing class. Missing 5th column defaults to `false`.
7. **Wrapper naming**: element type = wrapper name minus one trailing `s`; accessor = `Get` + (element substring after last `_`, or whole name): `GetCP`, `GetKey`, `GetByte`, `GetEl`, but `GetDString`, `GetDSystemFidFile`, `GetDSceneCharVis`, `GetDepthBufferStruct`.
8. **Offsets verbatim**, never normalized.
9. **Type mapping**: `uint`/`uint32`→`GetUint32` (AS type echoes declared token), `int`→`GetInt32`, `uint8`→`GetUint8`, `uint64`→`GetUint64`, `bool`→`GetBool`, `float`→`GetFloat`, `vec2/3/4`→`GetVec2/3/4`, `iso4`→`GetIso4`, `quat`→`GetQuat`, `nat2/nat3`→`GetNat2/3`, `string`→`GetString` (setter `const string &in`), `MwIdValue` 4th column → `GetMwIdValue`/`SetMwIdValue`. Value-type getter has extra parens: `return (this.GetUint32(off));`. Nod: `T@ get_X() { return cast<T>(this.GetNod(off)); }` and **with GS a setter**: `void set_Material(CPlugMaterial@ value) { this.SetNod(0x120, value); }`.
10. **Enum widths**: `(4)`→`GetUint32`, `(1)`→`GetUint8`; getter casts without parens: `return CGameCtnBlock::ECardinalDirections(this.GetUint32(0x58));`; setter stores raw (no `uint()` cast).
11. **`Inline:` verbatim** at 1 tab, in field-stream order — including methods, const methods, and field-like consts (`uint16 InvisibleOffset = 0x14;`).
12. **Invalid field lines silently skipped** (3rd column not G/S/GS) — no output, no error, exit 0, preceding comment dropped too. Byte-parity requires reproducing this leniency.
13. Non-generated neighbors: `MacroblockEnts.as.dep`, `MediaTrackerBlocks.as.dep` are hand-written legacy, not outputs.

## Corrigenda (2026-08-17, verified against goldens during parity implementation)

1. **Point 3 is wrong about empty classes**: an empty class gets **one** blank line between last ctor and `}`, not two (verified with `cat -A` on `DGameMgrMap_SBlockInstance`).
2. **Point 1 is conditional**: stdout ends `}\n\n\n` only when the last block is a `RawBufferElem` class; files ending in a Buffer wrapper end `}\n\n` (one blank line), e.g. `Mediatracker/BlockEntity.as`. Per-class `println!` framing reproduces both cases.
3. **Blank lines don't break comment attachment**: blank xtoml lines between a `#` comment and the following class header are ignored; the comment still attaches to the class (Macroblocks).
4. Bare `#` → `// ` **with trailing space**, confirmed in goldens.
